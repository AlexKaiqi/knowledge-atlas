# 可复用环境

按依赖与用途复用环境定义，每段探索有自己的运行实例和写入区。维护原则见 [探索与环境资产](../docs/EXPLORATION_ASSETS.md)。

| 环境 | 用途 | 入口 |
| --- | --- | --- |
| 共同工作浏览器 | Chrome、网页制作、交互实验与远端 MCP | [browser-workspace](browser-workspace/README.md) |
| Python 标准库 | 不依赖第三方包的小计算、文件处理和复现环境示例 | [python-stdlib](python-stdlib/README.md) |

新增环境先说明用途、进入与退出方式、运行入口、数据位置和最后验证情况。按需要选择 Dockerfile、依赖锁、Dev Container 或 Compose，不要求每个环境都有全套文件。暂时没有实际依赖的环境不提前创建。

环境定义进 Git，镜像作为可重建或外部分发的资产，用户数据与重要结果保存到容器外。不要为每段探索重复复制通用依赖，也不要把模型账号或 Agent 安装塞进共享镜像。


网页的「动手实践」也支持新建环境：先描述用途，再自行或请 Agent 补齐文件；分享后可加入共建、按版本修订和派生。这个目录维护 Git 自有环境，网页资产由 SQL 保存，不会自动落入此目录。Python 起点的基础 Dockerfile 从本目录生成公开模板；个人文件不进入静态构建。环境包导出与导回、共享版本和探索快照的规则见 [环境资产维护](../docs/EXPLORATION_ASSETS.md#在网页创建与共建环境)。
