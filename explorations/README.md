# 可接续的探索

围绕一个问题建立一个可读工作目录，例如 `explorations/<问题>/README.md`。先写当前问题、已有尝试和下一步；需要代码、输入、作品或运行记录时再增加文件。无需预先套章节或表格。

下一位参与者应能找到：为什么探索、目前知道什么、依据与分歧在哪里、如何运行、使用哪个 [环境](../environments/README.md)、结果对应哪些条件，以及接下来值得做什么。值得保留的运行可放 `runs/<运行名>/`，重跑不要覆盖已有证据。完整说明见 [资产维护](../docs/EXPLORATION_ASSETS.md)。

这里按可以共享的探索组织。私人笔记、原始聊天、临时大文件放 `.local/` 或仓库外；只把有授权且有复用价值的部分整理进来。不要求每次尝试都进入公共知识，也不把一次模型输出当作定论。

已有 `content/cases/` 教学案例和服务讨论仍在原处；本目录不是自动同步的副本。`research/` 与 `formal/` 独立维护，不因本目录建立就迁移或公开研究。
