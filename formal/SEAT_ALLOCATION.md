# 三座位静态配置：两份文档的校正与 Lean 4 验证

本文是采用 Gibbs 配置规则后的有限特例。基本研究问题与未预设熵形式的定义见
[代币、需求度量与权益配置](TOKEN_ALLOCATION_PROBLEM.md)；这里的闭式证明不构成从支付一致性
唯一推导 Gibbs 机制的证明。

## 结论先行

本轮只处理两份文档共同的“问题一”：需求已经给定时，如何在三个座位的六种完整配置之间形成一个概率分布。动态注意力市场、Matcher 学习与路由暂不进入本轮形式化。

第二份文档给出了可以验证的明确特例；第一份文档只写了六个排列，却没有在座位例子中明确 Claim。为避免替原文补错模型，本稿固定采用第二份文档的定义：

- \(D_{AB}\)：甲与乙相邻；
- \(D_C\)：丙坐在中间。

在三人线性排座中，这两个事件恰好互补。若把第一份文档理解为“甲和丙各自争同一把座位”，它们通常既不互补也不穷尽，下面的二元 sigmoid 公式便不成立。

在上述明确模型下，组合计数、Gibbs 概率闭式、参数平移不变性、有限参数不可能完全控制，以及单个座次的信息成本有限，均已由 Lean 4 + Mathlib 在无 `sorry` 的条件下通过。

## 1. 严格模型

令完整状态空间为从左到右的六种座次：

\[
\Omega=\{ABC,ACB,BAC,BCA,CAB,CBA\},\qquad P_0(\omega)=\frac16.
\]

| 座次 | 甲乙相邻 \(D_{AB}\) | 丙居中 \(D_C\) |
|---|---:|---:|
| \(ABC\) | 是 | 否 |
| \(ACB\) | 否 | 是 |
| \(BAC\) | 是 | 否 |
| \(BCA\) | 否 | 是 |
| \(CAB\) | 是 | 否 |
| \(CBA\) | 是 | 否 |

因此

\[
D_C=\Omega\setminus D_{AB},\qquad |D_{AB}|=4,\qquad |D_C|=2,
\]

以及

\[
P_0(D_{AB})=\frac23,qquad P_0(D_C)=\frac13.
\]

这里必须使用完整配置作为状态。若只记录“谁得到了什么”，却不记录所有人的联合座次，Claim 的交叠、互斥和成本都会失真。

## 2. 给定自然参数时的配置核

令 \(\gamma_{AB},\gamma_C\in\mathbb R\) 是已经给定的有限自然参数，并采用 Gibbs 倾斜

\[
P_\gamma(\omega)
=\frac{P_0(\omega)
  \exp\!\left(\gamma_{AB}\mathbf 1_{D_{AB}}(\omega)
  +\gamma_C\mathbf 1_{D_C}(\omega)\right)}{Z}.
\]

由于两个事件互补，四个 \(D_{AB}\) 状态的权重相同，两个 \(D_C\) 状态的权重相同。因此

\[
Z=\frac23e^{\gamma_{AB}}+\frac13e^{\gamma_C},
\]

并且

\[
\begin{aligned}
P_\gamma(D_{AB})
&=\frac{\frac23e^{\gamma_{AB}}}
        {\frac23e^{\gamma_{AB}}+\frac13e^{\gamma_C}}\\
&=\frac{2e^{\gamma_{AB}}}{2e^{\gamma_{AB}}+e^{\gamma_C}}\\
&=\sigma\!\left(\ln2+\gamma_{AB}-\gamma_C\right),
\end{aligned}
\]

其中 \(\sigma(x)=1/(1+e^{-x})\)。立刻得到：

1. \(\gamma_{AB}=\gamma_C=0\) 时恢复先验 \(P(D_{AB})=2/3\)，而不是 \(1/2\)。
2. 结果只依赖 \(\gamma_{AB}-\gamma_C\)。同时给两个参数加同一个常数不改变配置，因此参数对本身不可识别。
3. Claim 内部没有进一步区分状态的特征，所以条件分布保持均匀：四个相邻状态等概率，两个丙居中的状态等概率。
4. 对任意有限实数参数都有 \(0<P_\gamma(D_{AB})<1\)。有限 Gibbs 拉力只能逼近完全控制，不能达到完全控制。

最后一点直接否定了第一份文档中“有限 token 集中即可得到 \(P(D)=1\)”的表述。若制度必须保证完全控制，只能把它编码为硬可行域或收缩状态空间；那已不是同一个全支持、有限参数的 Gibbs 模型。

## 3. 信息成本

对基准概率为 \(p\in(0,1)\) 的硬 Claim \(D\)，若将“完全实现”的成本定义为

\[
\inf_{P:\,P(D)=1}D_{\mathrm{KL}}(P\|P_0),
\]

则最优分布是 \(P_0(\cdot\mid D)\)，成本为 \(-\ln p\)。代入座位计数得到

\[
u_{AB}=\ln\frac32,\qquad u_C=\ln3.
\]

若以 bit 计量，则分别为 \(\log_2(3/2)\approx0.585\) 与 \(\log_2 3\approx1.585\)。

固定六状态空间中，锁定某一个具体座次的基准概率是 \(1/6\)，所以成本为

\[
-\ln\frac16=\ln6<\infty.
\]

因此第一份文档的“微观锁定成本趋于无穷”不适用于这个有限座位模型。它只可能出现在无原子的连续空间中，且还需另行声明参考测度和绝对连续条件。

本轮 Lean 文件验证了上述三个对数恒等式；一般 KL 极小化定理本身尚未在 Lean 中展开。这是当前证明覆盖范围，不应把代数恒等式误报成已经形式化的一般变分定理。

## 4. 两份文档分别需要怎样校正

### 第一份文档

- 座位 Claim 未明确；若不是上述互补事件，二元 logistic 推导不能直接使用。
- \(\gamma_i=\kappa_i/(\pi u_i)\) 是额外选择的 token—参数映射，不是 KL 变分自动推出的结论。至少还需 \(\pi>0\)、\(u_i>0\) 和有限 \(\kappa_i\)。
- 把 \(\pi\) 称为内生价格需要额外的市场出清、预算或容量方程；当前只能称为兑换率。
- 有限 Gibbs 参数与 \(P(D)=1\) 相矛盾。
- 六状态中的单点成本是 \(\ln6\) 或 \(\log_2 6\)，不是无穷。
- 指数底数换算不能混用。\(e^{-x}=2^{-x/\ln2}\)，所以把 nat 参数直接塞进 base-2 指数会漏掉 \(1/\ln2\)。
- 由可加性得到指数形式还需要连续性或可测性等正则条件；要排除常数解并得到正系数，还需要严格单调或非退化假设。
- 若从约束优化推出 Gibbs/KKT 形式，需要写出可行性、正内点或 Slater 条件及对偶最优存在性。

### 第二份文档

第二份的座位计数与 Gibbs 闭式是正确的，也是本轮采用的基准，但仍须保留以下边界：

- 因 \(D_C=D_{AB}^c\)，两个特征线性相关；最简参数其实是一个差值 \(\delta=\gamma_{AB}-\gamma_C\)。
- “参数差决定结果”和“Claim 内条件中立”只在没有额外状态相关 Claim、成本或硬约束时成立。
- 若加入产权概率底线，未经约束的 sigmoid 可能不可行，必须在新的可行域中重新求解。
- 一般约束 Gibbs 定理仍需要有限对偶解和正内点条件；边界解不能用有限乘子的全支持公式表示。
- 该模型完成的是参数化配置，不是完整清算机制。它没有单独决定 token 发行、价格形成、支付、预算守恒或真实申报。

## 5. Lean 证明覆盖

形式化文件逐项证明了：

- 六种状态被完整、无重复地枚举；
- 两个 Claim 逐状态互补，计数为 \(4\) 与 \(2\)；
- 均匀先验概率为 \(2/3\) 与 \(1/3\)；
- 配分质量为 \(4e^{\gamma_{AB}}+2e^{\gamma_C}\) 且严格为正；
- 六个微观状态的归一化概率均为正且总和为一；
- 两个 Claim 的概率总和为一；
- \(P_\gamma(D_{AB})\) 的分式闭式和 sigmoid 闭式；
- 零参数基线、共同参数平移不变性和严格内点性质；
- 同一 Claim 内的状态保持等概率；
- \(-\ln(2/3)=\ln(3/2)\)、\(-\ln(1/3)=\ln3\) 和 \(-\ln(1/6)=\ln6\)。

以下内容没有被当前 Lean 文件证明，也不能从座位核直接推出：

- 一般有限空间上的 KL 极小化唯一性和完整 KKT 定理；
- token 到 \(\gamma\) 的唯一映射及 \(\pi\) 的内生形成；
- 支付、预算守恒、真实申报与激励相容；
- 产权概率底线；
- 问题二中的隐需求学习、动态 Bellman 方程、Matcher 路由和复制动态。

这些应作为后续相互独立的形式化层，而不应塞入已经通过的座位定理中。
