# 可共享的知识

这里维护 Git 自有的自由正文，供 clone 后的人和 Agent 阅读与修订。可以从 `knowledge/<稳定名称>/index.md` 开始，确有需要才增加附件或元数据。当前只有组织入口，尚未将旧内容批量迁入，也未自动接入网页索引。

按 [知识审阅规范](../docs/KNOWLEDGE_REVIEW.md) 说明问题、解释、依据、条件与深入方向；章节自由。用稳定名称或显式 ID 引用，改名时保留可追溯别名。相关知识以有理由的链接维护，涉及结论时指向具体版本；不必先建图数据库。Git 记录正文修订，审阅与变更理由可在正文附注、相邻记录或提交说明中保存。

探索过程留在 [explorations/](../explorations/README.md)，环境定义留在 [environments/](../environments/README.md)，知识只引用与解释有用的部分。这里按可共享内容组织，提交前不要带入私人对话、历史私稿、学习偏好或无授权数据。

现有 `content/knowledge/` 是网页种子适配层；服务知识仍由 SQL 管理。服务导出放在 `.local/exports/` 或仓库外；要整理成这里的自有条目，应记录来源服务 ID、具体修订、分享范围和“派生副本”的关系。没有自动双向同步，不能覆盖原服务记录或混称同一权威来源。
